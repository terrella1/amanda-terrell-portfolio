Completed project

Cloud Resume Challenge

I built and deployed this static portfolio as a hands-on AWS project. It gave me practical experience connecting cloud hosting, delivery, access management, and web security.

How it works

  • Amazon S3 hosts the static website files.
  • Amazon CloudFront delivers the site over HTTPS.
  • AWS IAM manages access and permissions for the cloud resources.
  • GitHub tracks the source code and publishes a copy with GitHub Pages.

What I worked through

I configured the hosting and delivery pieces, then troubleshot deployment and security issues—including a warning that led me to implement HTTPS through CloudFront.

Tools

Amazon S3 · AWS IAM · Amazon CloudFront · GitHub · GitHub Pages · HTML · CSS

Completed project

Serverless Visitor Counter

I built a visitor counter shared by my GitHub Pages and AWS-hosted portfolio. The page calls an Amazon API Gateway HTTP API, which invokes an AWS Lambda function written in Python. Lambda atomically updates the total in an on-demand Amazon DynamoDB table.

Infrastructure and tools

AWS CloudFormation · Amazon API Gateway · AWS Lambda · Amazon DynamoDB · Python · HTML · GitHub
